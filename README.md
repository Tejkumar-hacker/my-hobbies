### 🚀 Features
- Add hobbies with image URLs
- Display hobbies in card layout
- Mark/unmark favourites ⭐
- Edit hobby names ✏️
- Delete hobbies 🗑️
- Responsive UI

### 🛠️ Tech Stack
- React.js (Hooks)
- JavaScript (ES6+)
- CSS3

### 📷 Preview
Clean card-based UI with images and actions.

### 📚 Learning Outcomes
- useState hook
- Component-based architecture
- Conditional rendering
- Event handling
